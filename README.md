Задание 1: Уплотнить строку S1, удалив символы, встречающиеся в строке S2.
Идея реализации: Инициализировать s1,s2 которые отвечают за строчку в которой менять и строчку символов которые надо будет менять. Создать массив s3 в котором на места кодов по таблице ascii будем ставить 1 (это означает что символ есть в строчке s2) и проходим по строке s1. Если индекса элемента из строки s1 нет в нашем массиве то перезаписывааем с самого начала строчку и в конце добавляем конец '\0' и выводим строчку ( реализация в функции и функция не говорит, а возвращает полученную строчку s1)

Примеры:
s1 = "Hello World!" ; s2 = "l" / вывод - Heo Word!
s1 = "Kirill and Dima" ; s2 = "irill Dim" / вывод - Kanda
s1 = abcd ; s2 = abcd / вывод = пустота
