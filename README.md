Идея реализации: Первым делом нужно отобрать является ли строка в 10-ричке или нет путем отбора цифр. После того как мы выяснили что строка состоит из цифр начинаем работу с математикой. В коде реализовано деление в столбик числа на 4. и возвращаем остаток конечный ( если он равен 0 то кратно, если нет то не кратно)
